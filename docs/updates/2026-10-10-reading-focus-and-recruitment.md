# Reading a card and introducing the internship programs

This update helps a reader stay with a person or program card. Hovering or focusing a card quiets the surrounding content. An expanded profile or native program disclosure retains that reading context after the pointer leaves. The navbar and menu keep their normal appearance. Touch selects the card without consuming the tap; an outside tap restores the page. Focus can move freely to other controls. Escape restores the page without changing native keyboard handling.

The header now uses its existing opaque, theme-specific canvas surface in both prominent and calm states, and its inner content stays at full opacity. This keeps posters and photographs behind the sticky header from changing the logo/control contrast. Header sizing, direct targets, menu behavior and source colour roles are preserved.

The enhancement changes only opacity on sibling content branches. It does not add a backdrop, hide content from assistive technology, change tab order, disable links, move focus or lock scrolling. Detached or hidden cards are released after filtering, language changes and directory enhancement. Scrolling an active card fully outside the visible viewport restores the page without closing its details; returning to the card resumes the reading context. Scroll and resize checks are passive and limited to one animation frame, including the mobile visual viewport. Window blur, page exit and fragment navigation restore the page. Reduced-motion operation is immediate, and print/forced-colour views keep full opacity. With JavaScript unavailable, the static directory, program copy, form links and native details remain readable at their normal appearance.

The light/dark opacity values are local interaction choices, not new LDS colour tokens. Recruitment continues its scoped LDS 0.9.7 foundation pairs while the historical site shell and approved media retain their existing pinned versions. No decorative bracket or coloured selection rail is introduced.

The internship introduction now starts with actual work, Data + AI and learning with the team. Its program history, developer mentorship/code review and credited portfolio copy come from the owner-supplied 4 October 2026 v3 Set A announcements. Historical experience is not a promise of a permanent job. Duration, hybrid arrangements and the exact 400 THB/day allowance remain in a native logistics disclosure. The same renderer supplies initial Thai/English HTML and runtime language changes; it preserves open program and logistics disclosures when changing language.

The three original Set A poster PNGs, embedded attribution, dimensions and decoded application URL are unchanged. The public people registry, works, contribution roles, dates, statuses, consent and credit projection are unchanged. This update adds no application form, tracker, SDK or data request.

Validation includes controller-level pointer, keyboard, touch, expansion, native-disclosure, replacement and cleanup tests; bilingual initial/runtime content parity; the poster byte/dimension/form checks; and the full source/build validation. The Pages live-byte check also includes both new reading-focus dependencies. Rendered Thai/English review at narrow and desktop widths remains a separate release check.
